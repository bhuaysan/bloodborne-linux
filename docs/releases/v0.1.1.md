## Highlights

This release makes the game easier to install and to play with a controller alone, and it was checked on more distributions.

**What's new**

- **AppImage.** The package now also comes as one file, the recommended download. On its first start the launcher asks where to keep your settings, saves, caches and logs. The tar.gz stays for systems without FUSE.
- **Moving the data folder.** The launcher's Advanced page moves your settings and saves to another folder. It copies and verifies them before it removes the old ones.
- **Steam's Game Mode and gamescope.** The launcher and the game open fullscreen at the screen's size; before, the launcher came out small and blurred. Hold Back and Start for two seconds to leave the game and return to the launcher. `README.txt` in the package has the Steam steps.
- **Typing the hunter's name.** The name dialog of the character creation takes text from a physical keyboard. Its on-screen keyboard stays hidden until you use the controller, so it no longer covers the character editor.
- **More distributions.** The package played from a new game to the clinic on Ubuntu 22.04 and 24.04, Debian 12 and 13, Arch Linux and Bazzite, besides Fedora 44. The README lists what to install on each. `bb-run --check-system` tells you whether your system has what the game needs.
- **Fewer long frames while walking.** Copying changed buffers no longer holds up the GPU thread: on the walk through Central Yharnam at 60 FPS its longest pause dropped from 19–68 ms to under 6 ms.

**Fixes**

- A rare fault in video playback, seen in the opening movie: two threads could use the frame queue at the same time.

**Getting started**

Download `Bloodborne-Linux-v0.1.1-x86_64.AppImage`, make it executable (`chmod +x`) and start it. Choose the data folder, then put your dump in its `game/` folder or point the launcher at it. Without FUSE, start it with `--appimage-extract-and-run`, or take `Bloodborne-Linux-v0.1.1-x86_64.tar.gz`: unpack it into a folder you can write to and start `bb-launcher`. Check the download with `sha256sum -c --ignore-missing SHA256SUMS`.

Needs glibc 2.31 or newer (Ubuntu 20.04, Debian 11, SteamOS 3 and later), a Vulkan 1.3 driver, and fontconfig for the launcher. Settings and saves of v0.1.0 keep working.

**Known problems**

- A playthrough from the start to an ending has not been checked yet. Areas after Central Yharnam may have faults.
- Tested on one GPU: an AMD Radeon RX 7800 XT with Mesa RADV. NVIDIA and Intel GPUs are untested.
- Debian 13's own Mesa 25.0.7 hangs the GPU in the intro after the character editor. The driver from `trixie-backports` doesn't (#793).
- Steam's Game Mode was checked in gamescope with a virtual Steam controller, not yet on a Steam Deck or a Bazzite box (#757).
- One frame of about 70 ms roughly once a minute (#792).
- A rare crash during the logos and in the GPU worker (#491, #559).
