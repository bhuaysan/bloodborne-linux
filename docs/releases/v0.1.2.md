## Highlights

This release makes the game smoother while walking through Yharnam, fixes the GPU hang on Debian 13, and lets you choose the sound output.

**What's new**

- **Sound output.** The launcher's Picture and sound page has a new "Sound output" row, and `bb-run` takes `--audio-device NAME`. If the chosen device is gone (headphones unplugged), the game plays on the system default.
- **Smoother walking.** Two changes cut the work per frame in Central Yharnam. At 120 FPS, walking went from about 111 to about 118 FPS on the test machine, and the GPU is no longer busy almost all the time.
- **Faster launcher start.** The launcher no longer hashes `eboot.bin` on every start once it has passed the check.
- **The Old Hunters.** The game now sees The Old Hunters as owned on the Game of the Year dump. Its areas need a later save than we have, so this is not yet checked in play.

**Fixes**

- Debian 13 and other systems with Mesa 25.0: the GPU hung in the intro after the character editor. The package now works around it, so you no longer need `trixie-backports`.
- Possible broken pictures when the game copies block-compressed textures between different sizes.
- Rare faults in video playback: pausing, resuming and stopping a movie no longer race with the thread that pulls frames.
- Post-effect options (motion blur, chromatic aberration) no longer overwrite changes the game makes in the same frame.

**Getting started**

Download `Bloodborne-Linux-v0.1.2-x86_64.AppImage`, make it executable (`chmod +x`) and start it. Choose the data folder, then put your dump in its `game/` folder or point the launcher at it. Without FUSE, start it with `--appimage-extract-and-run`, or take `Bloodborne-Linux-v0.1.2-x86_64.tar.gz`: unpack it into a folder you can write to and start `bb-launcher`. Check the download with `sha256sum -c --ignore-missing SHA256SUMS`.

Needs glibc 2.31 or newer (Ubuntu 20.04, Debian 11, SteamOS 3 and later), a Vulkan 1.3 driver, and fontconfig for the launcher. Settings and saves of earlier releases keep working.

**Known problems**

- A playthrough from the start to an ending has not been checked yet. Areas after Central Yharnam may have faults.
- Tested on one GPU: an AMD Radeon RX 7800 XT with Mesa RADV. NVIDIA and Intel GPUs are untested.
- Steam's Game Mode was checked in gamescope with a virtual Steam controller, not yet on a Steam Deck or a Bazzite box (#757).
- One frame of about 70 ms roughly once a minute (#792).
- Walking through Yharnam at 120 FPS still has some long frames.
