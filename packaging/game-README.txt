Put your Bloodborne dump here (the folder with eboot.bin, CUSA03173 with update 1.09),
or leave it where it is and drag that folder onto the launcher window.

A dump in this folder is found without any setup, and the whole Bloodborne-Linux folder
can then be moved or renamed. Everything the game writes (settings, saves, caches, logs)
goes to user/ next to the launcher. Deleting the Bloodborne-Linux folder removes all of it.
